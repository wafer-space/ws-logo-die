# Components — what changes under each option

Brief inventory of source files that change per option.

```
RTL files that may change:
  vga_screensaver/wrapped_vga.v          # port width / internal wiring
  src/chip_top.sv                        # wire selection / instance
  src/chip_core.sv                       # unused-pad aggregation

Configuration / build files:
  vga_screensaver/pin_order.cfg          # if 'inputs.*' must match new width
  vga_screensaver/config.yaml            # unchanged in any option

Hardened views (regenerated by `make project`):
  vga_screensaver/runs/latest/final/lef/wrapped_vga.lef
  vga_screensaver/runs/latest/final/lib/wrapped_vga.lib
  vga_screensaver/runs/latest/final/nl/wrapped_vga.nl.v
  vga_screensaver/runs/latest/final/gds/wrapped_vga.gds
  vga_screensaver/runs/latest/final/mag/wrapped_vga.mag
  vga_screensaver/runs/latest/final/spef/...
  vga_screensaver/runs/latest/final/sdf/...

Verification surfaces:
  cocotb/chip_top_tb.py                  # if dead bits are stimulated

Upstream (Tiny Tapeout):
  vga_screensaver/tt-waferspace-vga-screensaver/src/tt_um_waferspace_vga_screensaver.v
                                         # touched only if forking (G3, G6, G7, G9)
```

## Per-option footprint

- **G1** (wrapper-shrink-to-5): wrapper port 7→5; chip_top
  wire-select; chip_core unused agg ↑2; **regenerate hardened
  views**.
- **G2** (document-only): docs only.
- **G3** (route-status-into-dead-bits): wrapper instance gains
  chip_core-driven internal wires; chip_core gains debug-out;
  *upstream fork* needed for the bits to be consumed.
- **G4** (preallocate-for-eFuse-(j)): depends on (j) interface
  (currently unspecified).
- **G5** (harvested-power-monitor-output): blocked — would need
  pad-cell swap → frozen-bondout violation.
- **G6** (tie-to-test-pattern): trivial wrapper internal logic;
  only useful in combination with G3.
- **G7** (wire-to-(f)-LFSR-debug-input): wrapper gains
  debug-input wires; cross-power-domain hazard requires (i).
- **G8** (internal-const-port-unchanged): wrapper internal
  const-tie only; **no port change → no re-harden**.
- **G9** (eFuse-mux-per-bit): large wrapper logic; (j) eFuse
  interface required.
